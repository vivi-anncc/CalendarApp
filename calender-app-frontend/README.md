# Calendar App Frontend

The frontend for **CalFlow**, a full-stack calendar application built as a learning project.

The goal of the project is to build a practical calendar application while gaining experience with modern frontend development, API integration, TypeScript, testing, and application architecture.

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- ESLint
- Prettier

## Features

- Calendar interface
- Create calendar events
- View calendar events
- Edit calendar events
- Delete calendar events
- API integration with the backend
- Responsive user interface
- Client-side form handling and validation
- Loading and error states
