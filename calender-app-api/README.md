# CalFlow API

The backend REST API for **CalFlow**, a calendar application built as a learning project.

## Tech Stack

- TypeScript
- Node.js
- NestJS
- PostgreSQL
- Prisma
- class-validator
- class-transformer
- Jest
- Oxlint

## Features

- Create calendar events
- View calendar events
- Update calendar events
- Delete calendar events
- Request validation
- RESTful API endpoints
- PostgreSQL database integration
- Database migrations with Prisma
- Automated testing with Jest

## Getting Started

### Prerequisites

- Node.js
- npm
- PostgreSQL

npm install
